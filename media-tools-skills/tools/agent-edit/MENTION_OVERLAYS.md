# Automatic mention timing

The editor selects meaningful objects and supplies aliases. The script automatically proposes times for those mentions. It does not fetch assets, identify imagery inside footage, or render overlays.

```powershell
.\tools\agent-edit\mention-plan.cmd "D:\project\cut.words.json" "D:\project\mentions.json" "D:\project\overlay-plan.json" --duration 30
```

Use the word-level JSON generated by the local caption batch, or a normalized transcript such as `{"words":[{"text":"folder","start":3.2,"end":3.7}]}`. Use final-cut timestamps, in seconds. Phrase matches ignore case and punctuation and can span adjacent words when there is no long pause. The planner uses at most one event per ID, selects higher priorities first, and limits overlap and frequency. The output lists the matched phrase, start/end, asset, and suggested placement for review.

Example `mentions.json`:

```json
{
  "rules": [
    {
      "id": "create-folder",
      "aliases": ["new folder", "create a folder"],
      "asset": "toolkit:assets/overlays/templates/mention-popups/folder.svg",
      "hold": 1.5,
      "priority": 10,
      "placement": "left-safe"
    }
  ]
}
```

An asset string is a label in the plan. Resolve `toolkit:` paths from the toolkit root and use absolute paths for project assets when rendering. Render a transparent SVG through the local motion workflow or use a PNG version for direct FFmpeg compositing. Keep the plan and outputs with the external project.
