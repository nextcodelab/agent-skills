# Sample Text Style Test Reel

A 15-second, 9:16 motion-graphics sample created from scratch because the Sample folder had no source footage. It showcases Soft Slide, Impact Pop, Marker Swipe, Clean Lower Third, and Word Stagger from the shared editable animated-text pack.

- `index.html` is the editable HyperFrames composition.
- `assets/` contains local GSAP, the reusable runtime, and selected JSON presets.
- `ffmpeg-filtergraph.txt` and `render-ffmpeg.ps1` are the local fallback recipe.
- `render-hyperframes.cmd` uses the toolkit's local HyperFrames CLI.

The MP4 is rendered by bundled FFmpeg because HyperFrames' headless browser startup crashes or hangs on this machine. All project/tool files live under `C:\Users\Robel\Desktop\video-editors`; only the final video and preview go in `C:\Users\Robel\Downloads\Sample`.
