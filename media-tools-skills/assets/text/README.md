# Reusable text library

Store curated hook lines, callouts, and campaign-safe phrases by language and industry. Keep copy separate from styling so agents can pair the same text with any cataloged animation. Save only source-backed or user-approved text; note context and tags next to each collection.

- `collections/` — reusable text phrases grouped by context and language.
- `templates/` — reusable text layout structures.
- `styles/animated-pack-01/` — 12 editable animated text styles, local SVG look previews, an interactive local preview board, JSON presets, and a seekable GSAP helper. Change the words and style values per clip; preserve the preset as a reusable library item.

When adding a reusable style, use a distinct ID, update its catalog, include a preview and tags, and record the best use. Prefer locally installed fonts and project-local files; avoid CDN scripts and remote assets.
