# Sound effects and generated cues

Keep reusable locally owned audio here. `synthetic/` contains original procedural WAV cues generated by `tools/media-lab/scripts/synth_sfx.py`. The piano-inspired sounds are synthesized tones rather than acoustic piano recordings. Rebuild them with `tools/media-lab/synth-sfx.cmd <kind> <output.wav> --duration <seconds>`.

Use the local `mix-bed` command to layer a quiet cue under existing video sound. Keep the original dialogue clear, check loudness/clipping, and listen to the rendered result. Imported samples should include their license and provenance before reuse.
