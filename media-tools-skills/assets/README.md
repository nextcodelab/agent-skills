# Shared asset library

Reusable assets are grouped by function and format. Search existing assets before creating another version. Keep original source, license/attribution, context tags, and usage notes next to imported assets; catalog reusable additions.

- `overlays/templates/` — reusable vector and FFmpeg overlay templates.
- `overlays/campaigns/ep5/` — episode-specific PNG/SVG cards.
- `stickers/svg/reaction-labels/` — editable local reaction-label SVG pack; see `stickers/catalog.json` and `stickers/README.md`.
- `stickers/png/` — reusable transparent raster cutouts.
- `captions/styles/` and `captions/animations/` — caption looks and motion definitions.
- `text/collections/` and `text/templates/` — reusable copy and layout structures.
- `animations/` and `effects/presets/` — local reusable motion/effect recipes.
- `sound-effects/` and `music/` — local audio assets with rights notes.
- `memes/images/`, `memes/videos/`, `memes/sounds/` — context-tagged meme assets; document rights and provenance before use.

For ordinary cards and stickers, use local reusable assets before authoring a new HyperFrames scene. Reserve HyperFrames for designed motion/overlays that need it.
