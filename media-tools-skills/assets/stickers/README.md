# Reusable stickers

## SVG reaction-labels pack 01

Editable, transparent-background local SVG assets at `svg/reaction-labels/`. Includes WAIT—WHAT?, PLOT TWIST, RECEIPTS, BIG FACT, NO WAY, HOLD UP, LEVEL UP, and OOPS! They use embedded vector shapes and system sans-serif fonts; no CDN, remote font, or external image is needed.

Use one sticker at a time, near the relevant spoken beat. Keep it clear of faces, existing title cards, captions, and platform UI safe areas. Treat humorous labels as editorial emphasis; remove one if it misrepresents the speaker or distracts from the point. The catalog records IDs and context tags. For future packs, add a unique ID, source/rights note if relevant, tags, intended timing/context, and update `catalog.json`.

These are original generic graphics, not screenshots, reaction photos, or sourced memes. Store externally sourced memes only when usage rights and provenance are documented.
